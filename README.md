A tiny, dependency-free entry that writes a single one-line joke to
`/output/entry.txt`. The joke is about working beside an AI coding agent
during a live demo that goes wrong.

## Run

```sh
node main.ts
```

The program takes no input, makes no network calls, and is deterministic.
It creates `/output` if needed and writes `/output/entry.txt` as UTF-8.
